## 📝 GABARITO

1. **B** - IA é o campo geral, ML é técnica dentro de IA, Deep Learning é técnica dentro de ML (redes neurais profundas).

2. **B** - Previsão numérica (vendas) com dados históricos = aprendizado supervisionado (regressão).

3. **C** - Agrupar sem rótulos pré-definidos = clustering (aprendizado não supervisionado).

4. **B** - Classificação: categorias (spam/não spam). Regressão: valores contínuos (preço, temperatura).

5. **C** - Aprender por tentativa/erro com recompensas = aprendizado por reforço.

6. **B** - Ciclo: Preparar dados → Treinar → Avaliar → Deploy → Monitorar (e iterar).

7. **C** - Amazon Rekognition: análise de imagens e vídeos, detecção facial, objetos, cenas.

8. **B** - Amazon Textract: OCR (Optical Character Recognition), extração de texto de documentos/PDFs.

9. **B** - Amazon Comprehend: NLP, análise de sentimento, extração de entidades, detecção de idioma.

10. **C** - Amazon Lex: construir chatbots conversacionais (mesma tecnologia da Alexa).

11. **A** - Overfitting: modelo "decora" dados de treino mas não generaliza para dados novos.

12. **C** - Amazon Forecast: previsões de séries temporais usando ML.

13. **C** - Amazon Personalize: recomendações personalizadas (produtos, conteúdo, marketing).

14. **B** - Feature engineering: criar/transformar variáveis relevantes para melhorar modelos.

15. **B** - Treino (aprender), Validação (ajustar hiperparâmetros), Teste (avaliação final imparcial).

16. **B** - Amazon Kendra: busca inteligente empresarial usando ML/NLP.

17. **B** - Transfer learning: aproveitar conhecimento de modelo pré-treinado para nova tarefa.

18. **B** - Comprehend Medical: extrair entidades médicas (medicamentos, dosagens, condições) de textos clínicos.

19. **B** - Modelo pré-treinado: já treinado em dados gerais, pode ser usado diretamente ou fine-tuned.

20. **B** - Amazon Transcribe: conversão de fala para texto (speech-to-text, ASR).

## 💡 Conceitos-Chave para Revisar

**Tipos de Aprendizado:**
- **Supervisionado:** Dados rotulados (classificação, regressão)
- **Não supervisionado:** Sem rótulos (clustering, redução de dimensão)
- **Reforço:** Aprender por tentativa/erro com recompensas

**Ciclo de Vida ML:**
1. Coleta e preparação de dados
2. Feature engineering
3. Treinamento
4. Avaliação
5. Deploy
6. Monitoramento

**Serviços AWS AI/ML:**
- **Visão:** Rekognition, Textract
- **Linguagem:** Comprehend, Translate, Transcribe, Polly
- **Conversação:** Lex
- **Recomendação:** Personalize
- **Previsão:** Forecast
- **Busca:** Kendra
- **Plataforma:** SageMaker
