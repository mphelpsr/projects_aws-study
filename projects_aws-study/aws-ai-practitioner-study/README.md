## 🎯 Como Usar

1. Responda as questões sem consultar as respostas
2. Anote suas respostas
3. Confira o gabarito no final de cada arquivo
4. Revise as explicações das questões erradas
5. Refaça os simulados após alguns dias

## ⏱️ Tempo Sugerido

- Questões individuais: sem limite (foco no aprendizado)
- Simulados completos: 45-50 minutos (proporcional aos 52% do exame)
